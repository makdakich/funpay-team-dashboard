# FunPay Hotkeys & Assistant ⚡
### Браузерный помощник продавца FunPay (Chrome Extension Manifest V3)

**FunPay Hotkeys & Assistant** — это нативное расширение для Google Chrome и Chromium-совместимых браузеров (Яндекс.Браузер, Microsoft Edge, Opera, Brave).

Проект создан для удобной работы с перепиской и продажами на FunPay:
* Быстрая вставка шаблонов сообщений по горячим клавишам (`F1`–`F8`) и через компактную панель.
* Независимые профили товаров (Roblox, Minecraft, Steam, Общий и любые пользовательские).
* Локальная финансовая статистика (раздельно по валютам, с явным учетом возвратов и настраиваемой «Моей долей»).
* **Безопасная архитектура**: расширение **НЕ отправляет** сообщения автоматически, **НЕ извлекает** автоматически скрытые cookies браузера и **НЕ передает** данные на сторонние серверы.

## 🛡️ Безопасность и хранение учетных данных

1. **Ручной ввод `golden_key`**:  
   В расширении первой версии **намеренно отключено автоматическое чтение cookies** браузера. Пользователь самостоятельно указывает свой сессионный токен `golden_key` в настройках, может проверить его валидность и в любой момент удалить нажатием одной кнопки.
2. **Изоляция данных**:  
   Токен сохраняется исключительно локально в `chrome.storage.local`.
3. **Запрет на логирование**:  
   Значение `golden_key`, `PHPSESSID` и любые токены сессий **никогда не выводятся в `console.log`** даже при включенном режиме разработчика (`Developer mode`).
4. **Отсутствие внешних бэкендов**:  
   У расширения нет внешнего сервера, нет аналитики и нет CDN. Все скрипты и стили упакованы внутри самого расширения.
5. **Минимальные permissions**:  
   В `manifest.json` запрашиваются только `storage`, `scripting`, `cookies` и доступ к хосту `*://funpay.com/*` (исключительно для установки пользовательского `golden_key` в изолированный стек Chrome и работы с сессией FunPay).

## 💰 Финансовые показатели, мультивалютность и возвраты

1. **Баланс vs Оборот**:  
   Баланс считывается исключительно со страницы FunPay (`span.badge.badge-balance`). Баланс **не рассчитывается** искусственно из суммы заказов.
2. **Раздельный учет валют (RUB / USD / EUR)**:  
   FunPay поддерживает расчеты в разных валютах. **Расширение категорически не складывает разные валюты между собой** ($1000\text{ RUB} + 10\text{ USD} \neq 1010$). Статистика ведется и отображается изолированно по каждой валюте.
3. **Возвраты (Refunded)**:  
   Заказы со статусом `refunded` (возврат) **не включаются в успешный оборот**. Количество и сумма возвратов отображаются в интерфейсе **отдельной строкой**, чтобы продавец наглядно видел объем возвращенных средств.
4. **«Моя доля» (не прибыль)**:  
   Расширение рассчитывает локальный показатель:  
   $$\text{Моя доля} = \text{Оборот (без возвратов)} \times \left(\frac{\text{Пользовательский процент}}{100}\right)$$  
   Процент настраивается (по умолчанию 10%). Этот показатель назван именно **«Моя доля»**, так как расширение не знает расходов и себестоимости товаров продавца.
5. **Временные периоды и часовые пояса**:  
   Даты FunPay (MSK / UTC+3) приводятся к точному UTC-timestamp, а группировка по периодам (**Сегодня**, **Последние 7 дней**, **Последние 30 дней**, **90 дней**, **Все время**) рассчитывается по **локальному календарному времени пользователя** (от 00:00:00 местных суток).

## 🛠️ Установка и запуск через chrome://extensions

### Шаг 1. Включение режима разработчика
1. Откройте браузер Chrome (или Яндекс.Браузер / Edge / Opera).
2. В адресной строке перейдите по адресу: `chrome://extensions/`.
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (**Developer mode**).

### Шаг 2. Загрузка распакованного расширения
1. Нажмите кнопку **«Загрузить распакованное расширение»** (**Load unpacked**).
2. В окне выбора файлов перейдите в папку проекта и выберите скомпилированный каталог:
   ```text
   .../fanpay-hotkeys-extension/dist
   ```
3. Нажмите **«Выбор папки»**. В списке появится карточка **FunPay Hotkeys & Assistant** ⚡.

## ⚙️ Настройка и проверка авторизации (golden_key)

1. Откройте сайт [https://funpay.com](https://funpay.com) и войдите в свой аккаунт.
2. Нажмите клавишу **F12** (Инструменты разработчика) -> вкладка **Application** (или «Хранилище») -> **Cookies** -> `https://funpay.com`.
3. Найдите куку с именем **`golden_key`** и скопируйте её строковое значение.
4. Откройте настройки расширения -> раздел **«FunPay API»**.
5. Вставьте ключ в поле и нажмите **«Сохранить токен»**.
6. Нажмите **«Проверить подключение»**: расширение выполнит проверочный запрос и покажет:
   ```text
   ● Подключено: ВашНикнейм (Баланс: X XXX ₽)
   ```

## ⌨️ Горячие клавиши (F1–F8) и быстрая панель

* **Профиль Roblox по умолчанию**:
  * `F1` — Приветствие
  * `F2` — Оплата
  * `F3` — Gamepass + плейс
  * `F4` — Способ передачи
  * `F5` — Ожидание
  * `F6` — Готово к передаче
  * `F7` — Завершение
  * `F8` — Другое
* **Контекстная безопасность**: клавиши F1–F12 перехватываются только на страницах `funpay.com` в контексте чата. Вне чата или на сторонних вкладках они работают штатно.
* **Переменные шаблонов**:
  * `{username}` — ваш никнейм на FunPay
  * `{order_id}` — ID текущего заказа (например, `#ABCD1234`)
  * `{product}` — товар из заказа
  * `{amount}` — стоимость
  * `{buyer}` — имя покупателя
  * `{gamepass}` — название геймпасса
  * `{place}` — плейс / сервер
  * *Если переменная не определена, подставляется пустая строка (никаких `undefined` или `null`).*
* **Быстрая панель**: компактный блок над формой ввода чата FunPay со списком кнопок шаблонов, метками клавиш и возможностью сворачивания в значок ⚡.

## 👥 Клиенты и история заказов

* **Идентификация клиентов**: покупатели группируются строго по **Buyer ID** (числовой неизменяемый ID профиля FunPay), а не по юзернейму, который покупатель может сменить.
* **История покупок**: по каждому клиенту фиксируются заказы, раздельные суммы по валютам и возвраты.
* **Поиск**: мгновенная фильтрация по ID заказа, покупателю и товару.

## 💾 Резервное копирование (Импорт и Экспорт)

В разделе **«Импорт / Экспорт»**:
* Экспорт формирует файл `fanpay-hotkeys-backup.json` со всеми профилями и шаблонами. Секретный токен `golden_key` **не включается в файл** ради безопасности.
* При импорте доступен выбор: **Объединить** (добавить новые шаблоны) или **Перезаписать** (полная замена).
