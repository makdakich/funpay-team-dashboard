# FanPay Hotkeys ⚡

Локальный менеджер горячих клавиш и шаблонов сообщений для продавцов на FanPay.
Позволяет быстро вставлять заготовленные ответы и инструкции в активное текстовое поле браузера с помощью глобальных горячих клавиш.

> **Важно**: Приложение работает полностью автономно, локально на вашем компьютере. Оно не подключается к аккаунту FanPay, не требует паролей, токенов и cookies.

---

## 🚀 Основные возможности

* **Двухпанельный тёмный интерфейс**: удобный список шаблонов слева и полнофункциональный визуальный редактор справа.
* **Глобальные хоткеи (Windows API)**: перехват клавиш через быстрый системный `RegisterHotKey` с защитой от повторного залипания (`MOD_NOREPEAT`) и встроенным debounce-кулдауном.
* **Безопасная вставка**:
  * Сохранение текущего буфера обмена пользователя перед вставкой и его автоматическое восстановление после неё.
  * Вставка в текущую позицию курсора без очистки уже набранного текста.
* **Три режима срабатывания**:
  1. **Вставить** (по умолчанию) — безопасная вставка без нажатия Enter.
  2. **Вставить + Enter** — автоматическая отправка сообщения (с предупреждением при выборе).
  3. **Только скопировать** — копирование в буфер обмена без эмуляции клавиш.
* **Система независимых профилей**:
  * Предустановленные профили: `🎮 Robux`, `⛏ Minecraft`, `🎮 Steam`, `🧪 Тест`.
  * Создание, переименование, удаление и мгновенное переключение профилей.
  * Запоминание последнего активного профиля при следующем запуске.
* **Переменные в сообщениях**:
  * Поддержка любых переменных в фигурных скобках: `{robux}`, `{price}`, `{buyer}`, `{order}` и т.д.
  * При срабатывании хоткея открывается удобное окно ввода с кнопками быстрых и недавних значений.
* **Быстрое меню (Quick Menu — `Ctrl + Space`)**:
  * Всплывающее Spotlight-окно поверх всех приложений с живым поиском по названию, тексту и клавише.
  * Вставка выбранного шаблона по клавише `Enter`.
* **Тестирование шаблонов (`▶ Тест`)**:
  * Просмотр готового текста без отправки в целевое окно.
* **Системный трей**:
  * Сворачивание при закрытии окна (X).
  * Быстрое переключение профилей и включение/отключение хоткеев прямо из контекстного меню трея.
* **Защита от потери данных**:
  * Горячая клавиша `Ctrl + S` для мгновенного сохранения.
  * Защита от потери несохранённых изменений при переключении между хоткеями или профилями.
* **Импорт и экспорт**:
  * Экспорт любого профиля со всеми его хоткеями в отдельный файл `.fhkprofile` (JSON) и импорт на другом ПК.
* **Ограничение приложений**:
  * Выбор: работать глобально во всех окнах или только в выбранных браузерах (`chrome.exe`, `msedge.exe`, `firefox.exe` и др.).
* **Локальная база данных SQLite**:
  * База автоматически сохраняется в `%APPDATA%\FanPayHotkeys\fanpay_hotkeys.db`. Настройки не теряются при обновлении программы.

## 🛠 Установка и запуск

### 1. Запуск из исходного кода (Python 3.12+)

```powershell
# Активация виртуального окружения
.\.venv\Scripts\activate

# Запуск приложения
python run.py
```

### 2. Запуск тестов

```powershell
.\.venv\Scripts\pytest -v
```

### 3. Сборка в автономный `.exe` (PyInstaller)

```powershell
.\.venv\Scripts\pyinstaller --noconsole --onefile --name "FanPayHotkeys" run.py
```

Готовый файл появится в папке `dist/FanPayHotkeys.exe`.
